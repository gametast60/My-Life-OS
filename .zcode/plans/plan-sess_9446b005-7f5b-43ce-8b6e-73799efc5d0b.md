# My Life OS — Brain Tree Update v1.1.2 (Plan v2 — revised)

Same scope as before. **3 changes from v1** per review: (a) SettingsModal stays a normal Modal (BottomSheet list now = 9), (b) all dead-code removals are now **conditional on a post-build full-project verification pass** (nothing is fix-deleted by name), (c) `FABPosition` removal is conditional on zero remaining references.

## 0. New shared infrastructure (created first, reused everywhere)

### 0.1 `src/hooks/useAutoResizeTextarea.ts` (NEW)
Powers Section 1.1. One hook, identical behavior everywhere:
- Resets `scrollHeight` on `value` change → handles edit-existing case (resizes immediately when value loads).
- `minRows` default ~2–3, `maxRows` default ~8–10; sets `rows` + `style.maxHeight`; scrolls natively beyond the cap.
- Uses `useLayoutEffect`: `height='auto'` then `scrollHeight` synchronously — smooth, no layout thrash.
- Exposes a stable ref so existing `onKeyDown`/Enter-to-send logic in `AICoachView` keeps working.

### 0.2 `src/components/BottomSheet.tsx` (NEW) — powers Section 1.2
Shared primitive on `motion` (already a dependency):
- `AnimatePresence` + `motion.div` overlay; sheet slides up ~180ms.
- **Swipe-down-to-dismiss**: `drag="y"`, `dragConstraints={{top:0}}`, `dragElastic`; closes on `dragEnd` if `offset.y > 100` or high velocity.
- **Safe Area**: `padding-bottom: env(safe-area-inset-bottom)` on sheet + sticky footer.
- Props: `isOpen, onClose, title?, headerIcon?, children, footer?, maxHeight?`.

### 0.3 Cross-cutting Mobile UX (global)
- `index.html`: viewport meta → `viewport-fit=cover, width=device-width, …` (enables safe-area insets).
- `index.css`: add `.safe-area-bottom { padding-bottom: env(safe-area-inset-bottom); }`.
- **Hide BottomNav when keyboard open**: new `src/hooks/useKeyboardOpen.ts` via `window.visualViewport`. `App.tsx` consumes → `hidden` prop on mobile nav only (desktop floating nav unaffected).
- Touch-target/spacing audit: bump sub-36px interactive icons (`p-1`→`p-1.5/2`, min `h-9/w-9`) and nudge mobile padding/gaps — conservative, no layout rewrites.
