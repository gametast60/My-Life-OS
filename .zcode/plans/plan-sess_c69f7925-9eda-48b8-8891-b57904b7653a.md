## แผน: สร้าง DateTimePicker แบบกำหนดเอง (Bottom Sheet)

### ปัญหา
`<input type="datetime-local">` (native) ใน `src/views/HomeView.tsx:226` และ `:298` เปิดตารางเลือกที่ล้นหน้าจอใน WebView และไม่มีปุ่มยืนยันชัดเจน (commit ตอน blur/change)

### วิธีแก้
สร้าง component ใหม่ `src/components/DateTimePicker.tsx` เป็น **bottom sheet modal** แทน native input ทั้ง 2 จุด

### ไฟล์ที่เปลี่ยน

**1. สร้าง `src/components/DateTimePicker.tsx` (ใหม่)**

Bottom sheet ลอยจากขอบล่างจอ (`fixed bottom-0 inset-x-0`) ครอบคลุม:
- **Props:** `isOpen`, `value` (string `YYYY-MM-DDTHH:mm`), `onConfirm(value | "")`, `onClose`
- **ลักษณะ:**
  - Header: ปุ่มปิด (X) + หัวข้อ "เลือกวันและเวลา"
  - **ปุ่มลัด:** วันนี้ / พรุ่งนี้ (ตั้งเวลา default เป็นเวลาปัจจุบัน)
  - **ปฏิทินรายเดือน:** ปุ่มเลื่อนเดือน ◀ ▶ + ตาราง 7x6 วัน คลิกเลือกได้ (ไฮไลต์วันที่เลือกสีเขียว)
  - **ตัวเลือกเวลา:** dropdown/scroll `<select>` สำหรับ ชม. (00-23) และ นาที (00/15/30/45) หรือ input number — ใช้ `<select>` เพื่อไม่ให้ล้นจอและใช้งานง่ายบนมือถือ
  - **Footer ปุ่ม:** "ยกเลิก" (เทา) + "ยืนยัน" (เขียว gradient แบบเดียวกับแอป) + ปุ่ม "ลบเวลา" (ถ้ามีค่าอยู่)
- **ธีม:** ใช้สีเดียวกับแอป — `bg-[#131913]`, `text-[#EBF1EA]`, accent `#6B9361`/`#4E7345`, rounded-3xl
- **Escape:** ปิดด้วยปุ่ม Escape (เหมือน BrainCardModal)
- **ป้องกันสอบคลาย:** กด backdrop ปิด modal
- **State ภายใน:** เก็บค่า `tempValue` แยกจาก prop — ยืนยันแล้วถึงเรียก `onConfirm`

**2. แก้ `src/views/HomeView.tsx`**

- **จุดที่ 1 (บรรทัด ~222-241):** ส่วนเลือกวันเวลาตอนเพิ่ม reminder ใหม่
  - เพิ่ม state `isDateModalOpen`
  - แทน `<input type="datetime-local">` ด้วย **trigger button** ที่แสดงวันเวลาที่เลือก (หรือ placeholder "กำหนดวัน/เวลา") + ไอคอน Clock → คลิกเปิด modal
  - render `<DateTimePicker>` ด้านล่าง

- **จุดที่ 2 (บรรทัด ~297-303):** ส่วนแก้ไข reminder (inline edit)
  - แทน `<input type="datetime-local">` ด้วย trigger button เดียวกัน
  - ใช้ state `isEditDateModalOpen` แยก
  - render `<DateTimePicker>` อีก instance

### ข้อดีของวิธีนี้
- ✅ ไม่พึ่ง native picker → **แก้ปัญหาล้นหน้าจอ** อย่างสิ้นเชิง
- ✅ มีปุ่ม **ยืนยัน/ยกเลิก** ชัดเจน
- ✅ คงรูปแบบข้อมูล `YYYY-MM-DDTHH:mm` เดิม → ไม่ต้องแก้ App.tsx / types / db
- ✅ ใช้ธีมเดียวกับแอป → สอดคล้องกับ ConfirmDialog / BrainCardModal ที่มีอยู่
- ✅ Reusable — ใช้ได้กับทั้ง 2 จุดใน HomeView

### การทดสอบ
- `npx tsc --noEmit` ผ่าน
- ทดสอบบนมือถือ: กด trigger → modal ลอยขึ้นจากล่าง → เลือกวัน/เวลา → กดยืนยัน → ค่าถูกตั้ง
